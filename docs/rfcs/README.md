# Requests for Comments

Anything that changes the public API, the command line, or a generated file
format starts here, before the code, so the design is reviewed once and in
the open.

## Process

1. Copy `0000-template.md` to `NNNN-short-title.md` with the next free
   number, and open a pull request containing only the RFC.
2. Leave it open for comment for at least seven days.
3. A maintainer accepts it (merged as "Accepted"), asks for changes, or
   declines it with the reason recorded in the file.
4. The implementation pull request links the accepted RFC.

Accepted RFCs are the history of why the API looks the way it does.
